# AIGF 方案页映射（aigf_focus）

本演示对应原生未来 AIGF 能力焦点编码。每条一句，标明在演示中的落点。

| 编码 | 一句话映射（演示落点） |
|------|------------------------|
| **01CS** | **客户与案件上下文**：案件列表与案头摘要（申请人脱敏、产品、金额、渠道、城市）构成预审输入上下文。 |
| **03CO** | **协同编排**：顶栏 5 步主路径把「材料/规则 → AI → 人审 → 度量」串成可点击工作流，而非孤立工具。 |
| **08VT** | **可验证轨迹**：人工复核页审计时间线记录进件、规则、AI 建议与人审决策，演示事件可追溯。 |
| **07VO** | **可观测运营**：度量看板展示预审量、采纳率、人审耗时、漏斗与人机一致率，支撑运营可见。 |
| **11OO** | **人机闭环操作**：复核页「采纳/退回/拒绝」+ 必填理由，体现 AI 建议进入人工决策闭环。 |
| **14RG** | **规则与治理边界**：材料/规则页展示规则引擎命中与预警级别，AI 建议不绕过准入规则。 |
| **16RT** | **风险与责任透明**：AI 建议页标明置信度、关键因子与「终裁权在人」，决策理由写入审计。 |
